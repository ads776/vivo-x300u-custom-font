Vivo OriginOS 7
Custom System Fonts

The vivo font store is garbage! Bring your own fonts for actual customization. No root needed!

TESTED CONFIGURATIONGlobal X300 Ultra
Build 17.1.6.36.W30
Inter · GC Tune 1.2.2 · Game Cube 15.0.04.00_sc
READ THIS FIRST

This process applies your chosen font across the phone UI, but it will not appear in Settings’ font selector. The selector remains checked on the font that was active before this process. Selecting another font may overwrite the change; rerun the procedure to restore your custom font.

This is an unofficial workaround using GC Tune’s privileged command channel through Game Cube; it does not use root. The tested configuration is listed below. Other Vivo phones, firmware, and tool versions may behave differently. Proceed at your own risk.

01

Check compatibility first.

Tested Setup

  • Hardware: vivo X300 Ultra, global India variant
  • OS: OriginOS 7, build PD2547F_EX_A_17.1.6.36.W30
  • Themes: 23.4.2.2 (version code 234220)
  • Game Cube: 15.0.04.00_sc (version code 1500400)
  • GC Tune: releases; tested version 1.2.2 (version code 13)
  • Font tested: Inter Variable
  • Device running ADB and connected to phone
If your versions differ, this may not work — proceed at your own risk.

GC Tune’s command channel depends on Game Cube behavior and may change with app or firmware updates. Use a legally obtained TrueType font.

02

Prepare tools and the font.

Enable Developer Options and USB debugging.

On the X300 Ultra, open Settings → About Phone → Version Info and tap Software Version until Developer Options are enabled. Then open Settings → System Management → Developer Options and enable USB debugging. Connect the phone and authorize the ADB computer.

Phone settings

Apply a free font from the vivo font store first.

In Themes, find and apply any free font before continuing. This keeps the default fonts selectable if the workaround fails. The Settings selector will continue to show its check mark beside that downloaded font, even while the custom font is active.

Install GC Tune from its releases page and grant its permission.

On your computer, replace the example APK path with the downloaded file. This installs the app and grants a protected-settings permission. GC Tune’s interface is entirely in Russian; a second phone with Google Translate’s camera translation feature can help navigate it.

ADB · local computer
ADB · local computer 
adb install --user 0 "/path/to/gctune-v1.2.2.apk"
adb shell pm grant --user 0 com.poc.gctune android.permission.WRITE_SECURE_SETTINGS

Check the privileged command channel.

Add GC Tune in Settings → Ultra Game Mode → supported/add games. Open its Shell screen and run the check. If it times out or errors, swipe in from the upper-right edge to open the Game Cube overlay while the request is waiting, then retry. Continue only if output includes uid=1000(system) and u:r:system_app:s0. This is system UID, not root.

GC Tune · Shell
Paste into GC Tune 
id; id -Z

The Game Cube overlay may need to be open for the command channel to respond. A timeout is inconclusive; do not proceed without the expected identity.

Choose a font and a fresh filename.

Use a font you are allowed to use. Inter Variable was tested (SHA-256 begins 0be2399e and ends c7ac3a8); that does not establish compatibility for every weight, app or language. Example source path: /path/to/YourFont.ttf. Example new name: custom-font-2026-10-23.ttf. Avoid spaces and use an unused name.

03

Stage a separate font file.

Copy the font to phone Downloads.

Update both paths for your font and fresh filename. The no-overwrite guard will fail if the destination already exists; choose another name if so.

ADB · local computer
ADB shell · local computer 
adb shell -T 'set -C
cat > /sdcard/Download/custom-font-2026-10-23.ttf' < "/path/to/YourFont.ttf"

Copy it into the protected font directory.

Paste into GC Tune. Check the listing and checksum before proceeding.

GC Tune · Shell
Paste into GC Tune 
(set -C; cat /storage/emulated/0/Download/custom-font-2026-10-23.ttf > /data/vfonts/custom-font-2026-10-23.ttf) && ls -lZ /data/vfonts/custom-font-2026-10-23.ttf && sha256sum /data/vfonts/custom-font-2026-10-23.ttf

Set readable file permissions and inspect the security label:

Paste into GC Tune 
chmod 644 /data/vfonts/custom-font-2026-10-23.ttf && ls -lZ /data/vfonts/custom-font-2026-10-23.ttf

Confirm your computer can read the staged file.

This read-only checksum should match the one reported by GC Tune. Ordinary ADB shell cannot write to this protected directory.

ADB shell · local computer 
adb shell sha256sum /data/vfonts/custom-font-2026-10-23.ttf
04

Switch the link, then verify.

Pause here. Save the current link target and verify the font’s checksum. The next command changes the active system font link. Record the current target from readlink /data/vfonts/VivoFont.ttf before switching. Replace the quoted expected target in the command with that exact value. If the check fails, stop. This is a consequential phone change.

Use a fresh temporary link name. The command changes the active link only if the current target matches the value you recorded.

GC Tune · active font change 
readlink /data/vfonts/VivoFont.ttf | grep -Fx '/data/vfonts/REPLACE_WITH_RECORDED_ORIGINAL_TARGET.ttf' && ln -s /data/vfonts/custom-font-2026-10-23.ttf /data/vfonts/custom-ready-2026-10-23.link && mv -fT /data/vfonts/custom-ready-2026-10-23.link /data/vfonts/VivoFont.ttf && ls -lZ /data/vfonts/VivoFont.ttf && sha256sum /data/vfonts/VivoFont.ttf

The recorded test then sent a refresh broadcast and restarted normally. Broadcast alone did not visibly refresh text.

GC Tune · request refresh 
am broadcast -a android.intent.action.FONT_CONFIG_CHANGED

After a normal restart, check the link and rendered font from your computer:

ADB shell · local computer 
adb shell 'readlink /data/vfonts/VivoFont.ttf; sha256sum /system/fonts/VivoFont.ttf'

Compare a few distinctive characters in system UI against the font you selected before the change. QQQ 999 distinguishes the tested Inter and original font, but is not a universal test; choose characters that differ between your two fonts. Confirm visually as well as with the active path and checksum.

05

Rollback is prepared, not tested.

The original selected font file should remain preserved. Record its exact target before switching. This rollback command is a template; replace the target and use a fresh temporary-link name. Rollback was prepared but never executed on-device. Restart may be needed after switching back.

GC Tune · unverified rollback 
ln -s '/data/vfonts/REPLACE_WITH_RECORDED_ORIGINAL_TARGET.ttf' /data/vfonts/original-restore.link && mv -fT /data/vfonts/original-restore.link /data/vfonts/VivoFont.ttf && ls -lZ /data/vfonts/VivoFont.ttf
This is not tested boot-failure recovery. Do not rely on it as an emergency recovery method.
06

Limits and troubleshooting.

  • No Settings entry: this swaps the active font link; it does not add a font to the Themes selector.
  • ADB permission denied: expected for direct writes in /data/vfonts. File modes alone do not bypass SELinux security.
  • GC Tune times out or returns an error: swipe in from the upper-right edge to open the Game Cube overlay while the request is waiting, then retry. A timeout is inconclusive; do not assume the command ran.
  • Font looks unchanged: restart normally; the broadcast alone did not refresh the visible font.
  • Settings selector still shows the pre-process font: expected; its check mark does not track this active-link change.
  • Avoid GC Tune’s automatic font installer: inspected behavior may overwrite top-level TTF files.
  • Persistence limits: activation was visible across several normal restarts. OTA updates, uninstall, Themes changes, and broad compatibility remain unverified.
